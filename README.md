# 和泉川 歳時記カレンダー

はてなブログ「[kataroのつぶやき](https://kataro.hatenablog.com/)」の記事を、
**「今日と同じ日付」で過去にさかのぼって読む**ためのカレンダーです。

- 収録: 2004-01-01 〜 2026-08-15 の **8,322件**（7,758日分）
- 小動物 / 植物 / イベント の3シーンで絞り込み
- 記事にYouTube動画がある場合はアイコンを表示（621件）
- 写真と本文は元記事へのリンクです（このサイトは記事本文を保持していません）

公開URL: https://hitujiteio.github.io/izumigawa/

## 権利について

記事・写真の著作権は、すべて原著者である kataro 氏に帰属します。
本ページは公式のものではなく、原著者への贈り物として個人が作成した索引です。
画像は元サイトを直接参照しており、複製・再配布は行っていません。
検索エンジンには登録しない設定（`noindex`）にしています。

**原著者のご希望があれば、直ちに公開を停止します。**

## 更新

毎朝7時、`izumigawa_app.py` がブログを確認して新しい記事を取り込み、
`izumigawa_deploy.py` が変更があった場合のみこのリポジトリへ反映します。
